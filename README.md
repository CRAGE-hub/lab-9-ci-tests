# Лабораторная работа 9

Небольшой учебный калькулятор и pytest-тесты для проверки запуска через GitHub Actions.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
python -m pytest -v
```

Workflow находится в `.github/workflows/run-tests.yml`. Он запускает тесты при `push`, `pull_request` и вручную через `workflow_dispatch`.

Чтобы проверить workflow в GitHub, загрузите **содержимое этой папки** в корень публичного GitHub-репозитория. Затем откройте вкладку **Actions**, выберите **Python tests** и дождитесь успешного запуска. Зелёная галочка появится только после фактического выполнения workflow на GitHub; локальный запуск ее не подтверждает.

Подробное описание задания, тест-план, листинги файлов и проверенные результаты находятся в [Отчет_ЛР9.md](Отчет_ЛР9.md).
